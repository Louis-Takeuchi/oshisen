# オシセン！ 研究対応設計

更新日：2026-09-18
対象：2026年 茨城県議会議員選挙・つくば市選挙区 / Phase 0
状態：候補者未登録、Podcast取材未実施、研究参加募集前

この文書は、ユーザーが2026-09-18に提示した「オシセン！の研究対応設計案」を実装へ移すための方針です。
[要求定義v1](requirements-v1.md) は当初の履歴として保持します。総合一致率中心の表示、仮名4名、政策のみ／政策＋人柄の主比較など、矛盾する旧仕様より本書の方針を優先します。
土浦市選挙区から対象を変更しますが、旧対象での選挙実施の有無を、このプロジェクトで検証済みの事実として公表しません。

## 1. 目的と今回の境界

政治家の総合点を出すのではなく、政策の回答を一問ずつ見比べ、経験・選択・本人が挙げた判断理由・条件を原発言へたどれるようにします。
主研究の問いは「同じ取材内容を共通形式で比較できるようにすると、発言内容と根拠を正しく把握しやすくなるか」です。
投票先の予測、人格の採点、投票率改善の証明を目的として扱いません。効果は未検証です。

今回実装するのは、候補者データがなくても進められる質問台帳・回答照合・取材形式・表示・研究準備です。
架空の候補者、発言、収録情報、外部資料を埋めません。承認済みの取材素材が揃うまで、公開画面は空の状態と準備状況を伝えます。

## 2. P・H・Nを分ける

| 区分          | 入力                                     | 用途                               | 使わないこと                         |
| ------------- | ---------------------------------------- | ---------------------------------- | ------------------------------------ |
| P：政策       | 候補者と利用者が同じ版の命題に回答       | 設問単位の選択肢と根拠の対照       | 人物全体の一致度、順位               |
| H：共通取材   | 候補者本人が語った経験・選択・理由・条件 | 共通項目から原発言へ戻る           | 性格点、誠実さ等の運営による推論     |
| N：情報ニーズ | 利用者が選ぶ最大3テーマと情報の種類      | ページ案内、全候補者共通の絞り込み | 政策の重み、候補者への加点・優先表示 |

Nのテーマは既存のタブ内保存を使い、情報種類は画面内だけで保持します。Pの回答値やHの内容と合算しません。
診断完了をH閲覧の条件にしません。`/stories` と `/interests` は独立した入口です。

## 3. 質問台帳と版

実装：`lib/question-ledger.ts`、`lib/policy.ts`、`/policy-register`。
登録方法の詳細は [question-ledger.md](question-ledger.md) を参照します。

- 現行8問は操作確認用の草案として保持します。
- 新設計案の8問は保留中の候補として記録し、確認済みの県政問題として表示しません。
- 台帳には採用状況、根拠・採用理由、未採用・保留理由、県との関係、制度・基準時点、確認する事項を持たせます。
- 質問文、条件、尺度、補足説明の版を照合します。意味が変わる変更で旧回答の数値を引き継ぎません。
- 基本の尺度は「賛成／どちらかといえば賛成／賛成でも反対でもない／どちらかといえば反対／反対」です。
- 判断保留は別状態。情報不足・未整理の理由は任意です。スキップとも区別します。
- 用語、現状・県との関係、主な論点、出典の固定説明を分けます。未確認の事項は未確認のまま見せます。

初期の版識別子は台帳 `question-ledger-2026-09-18-v1`、質問 `draft-2026-09-18-v1`、尺度 `agreement-5-v1`、補足 `draft-help-2026-09-18-v1` です。
8問が政治観・県政全体を代表すると説明しません。16〜24候補→共通8問、12〜20名の認知インタビュー等の人数は、ユーザーの設計案にある開始案で、先行研究の最適値ではありません。

公開前には、住民の自由回答と政治・行政の資料を別々に集め、質問候補を照合します。報道・公開投稿の件数を支持率や住民全体の関心率として扱いません。
認知インタビューでは質問の言い換え、判断対象、足りない情報を確認します。回答ができたことと、意図した意味を理解したことは分けます。

## 4. 非集約の政策照合

`comparePolicyAnswers` は、設問と版・尺度が対応するか、候補者の回答が公開可能な本人回答かを確認してから、選択肢の同異を返します。

1. 同じ設問ID・質問版・尺度版・条件を含む補足版か確認する。
2. 公開可能な本人回答か確認する。
3. 両者が5段階の回答を持つ場合のみ「同じ回答」「異なる回答」を示す。
4. 原回答と理由・条件・出典を接続する。

中立の回答、利用者の判断保留・スキップ・未回答、候補者の未回答・確認中、版違いは区別します。
欠測を中立に置き換えず、過去の発言や公式サイトから今回の本人回答を推定しません。
一問だけの場合も原回答は見られますが、総合一致率・距離・順位は返しません。
同じ選択肢から、同じ理由・将来行動・人格を推定しません。

通常の一覧と比較は氏名読みの五十音順を基本にし、閲覧履歴や利用者属性から候補者を優先しません。
本番研究の候補者順は、参加者間で均衡化し同一参加者内で安定させる計画です。現時点のローカル表示確認は、本番の割り付け機能ではありません。

検証対象は投票先の予測精度ではなく、誤結合・不正な補完・出典不一致の防止です。質問順の入れ替えや候補者追加で既存の対照が変わらないこと、版違いを照合しないことも確認します。

## 5. Hの共通取材と情報ブロック

共通6問：取り組みの背景、判断と選択、意見の相違、想定外への対応、考えの変化・継続、暮らしとの接点。
共通の追加質問は、時期、本人の行動、別の選択肢、判断が当てはまる条件を確かめます。
公職以外の経験も対象にし、考えを変えた場合だけを好意的に扱いません。

各ブロックに以下を保持します。

- 本人が語った経験、そのときの選択・行動、本人が挙げた理由、条件・留保。
- 引用、前後の文字起こし、発言区間、Podcastの該当箇所と全編。
- 本人回答・本人の回顧・公式記録・編集部要約等の情報の種類と確認状況。
- 収録日、回答日、公開版、訂正・追記、関連する政策質問。

要点→引用と前後の文脈→原音・全編・一次資料の順で深く読めるようにします。
「今回の回答では言及なし」を、その人に経験がないことや能力がないことに読み替えません。
政策と関連取材には双方向のリンクを設けます。

収録30〜40分、要点100〜160字などは試行の目安です。字数を守るために重要な条件を落としません。
依頼・収録・追加質問・編集・本人確認の条件は候補者間でそろえます。公開を望まない私生活を人物像の材料として掘り下げません。

## 6. 制作と承認

予定工程：収録→文字起こし案→原音照合→発言区間抽出→共通形式の下書き→別担当者の文脈確認→本人による発言趣旨確認→承認版の公開。
AIを制作補助に使う場合も、入力資料の範囲、発言区間ID、否定・条件・時期・話者を保持し、足りない情報を生成して補いません。
本人の趣旨確認、原音との一致、独立資料による事実確認はそれぞれ別です。
公開する文章は承認済みの固定文とし、アクセス時に自由生成するチャットをPhase 0の前提にしません。

今回、認証付き管理画面・取材素材のサーバー保存・実際の公開承認運用は導入しません。JSON構造の確認は、確認担当者が事実を審査したことの代わりにはなりません。

## 7. B/C表示とローカル確認

- B：承認済みの発言ブロックを取材順に表示。
- C：同じブロックを共通項目で整理して表示・比較。
- 本文、引用、分量、候補者、政策質問、回答照合、Podcastと文字起こしの提供範囲をそろえる。
- 比べる対象は「共通形式の比較UIを含む設計全体」。見出しだけ、横並びだけ、Podcastだけの効果とは呼ばない。

`/research` で手元のJSONを読み込み、構造を検証して表示確認します。データは画面メモリのみで扱い、ブラウザの保存領域やサーバーには保存しません。
確認操作の記録は任意です。自由閲覧/理解課題、B/C、文脈展開、原資料へのクリック、経過時間、再クリックを区別します。
固定識別子 `local-check` は開発用で、研究参加者IDの発行ではありません。
記録停止・消去・別ファイル読み込み・再読み込み・タブ終了で確認記録を消します。手動ダウンロードしたファイルは利用者が削除します。
通常の任意操作記録と実装上も分け、研究への同意や本番集計と誤認させません。

## 8. 研究開始前に決めること

主指標は、サイトを参照しながら発言内容と根拠の両方を正しく把握できた課題の割合です。
理由・条件・根拠箇所・資料だけでは不明なことを含む課題を試行します。検証済みの人格理解尺度を採用したとは説明しません。
サイトを使って探せること、記憶に残ること、分かったと感じることは分けて測ります。
原資料への自発的な移動は副次指標とし、課題の指示に従った移動とは分けます。
画面内への表示を読了、リンククリックを視聴、再生時間を理解とは扱いません。

研究を始める前の未確定事項：

- 取材・情報収集と承認済み共通素材。
- 主比較、主要評価、採点基準、必要人数、終了基準、除外、欠測、分析方法の固定。
- 募集経路と対象者（初期案は18〜29歳）、在学者への偏り、地域との関係の扱い。
- 通常利用と分けた研究参加の説明・同意。
- 成年のデータ管理責任者・協力研究者、保存先・保存期間・削除とアクセス権限。
- 研究倫理・個人情報・選挙関係の確認。
- 本番の順序均衡化、割り付け、参加者をまたぐ収集と分析。

無作為割付だけで若者全体の代表性は得られません。理解に差が出ても、投票率改善を示したとは結論しません。
