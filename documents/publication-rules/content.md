# オシセン！候補者向け取材コンテンツ取扱掲載規約

2026年茨城県議会議員一般選挙版｜統一改訂案 v2.3｜2026年10月26日作成

対象：つくば市選挙区・土浦市選挙区

## 第1条 目的、対象及び運営主体

1. 「オシセン！」（以下「本サービス」）は、政策、経験及び判断の背景に関する候補者の一次情報を利用者が確認・比較できる情報サービスです。特定の候補者の当選又は落選を目的とする推薦・投票依頼は行いません。

2. 対象は2026年茨城県議会議員一般選挙のつくば市選挙区及び土浦市選挙区とします。各選挙区の全候補者及び把握した立候補予定者に、党派、現職・新人、運営との関係等を問わず共通条件を提示します。

3. 対外的な運営表示名はオシセン！運営チーム、成人運営責任者及び成人掲載責任者は堀下 恭平（兼務）です。候補者との契約及び利用許諾の受領名義は、堀下 恭平（個人名義を想定する案）として、実際の契約当事者となることへの本人最終確認を経て正式確定します。正式確定前に本規約による新規の候補者同意取得を開始しません。独立した異議審査担当者は現段階では置かず、第4条・第21条の再検討手続で対応します。本人承諾のない所属組織を運営主体と記載しません。個人住所その他の非公開連絡先を公開文書に記載せず、法令上必要な情報は第28条の窓口から本人の求めに応じて遅滞なく案内できる体制を整えます。

4. 別の選挙や後継サービスへの資料転用は本規約の許諾対象外です。

## 第2条 定義

1. 「参加者」は本人確認と第5条の同意を完了した候補者又は立候補予定者です。「候補者」は公式届出により確認された者とします。

2. 「提供資料」は政策回答・人となり回答・プロフィール・写真・参考資料、「原記録」は未編集の音声・許諾された映像・回答原票・文字起こし、「掲載コンテンツ」は公開される回答、写真、音声・映像、要約、文字起こし、切り抜き等です。

3. 「確認版」は版番号付きの公開前資料、「訂正」は原記録との不一致・事実誤認・権利侵害等の是正であり、事後的な政策変更・印象改善とは区別します。

4. 「政策回答」は共通8問に対する本人提出又は明示的確認済みの選択回答、理由、条件、根拠、「人となり回答」は共通6問についての本人の経験・判断背景、「基本情報」は公的資料などで確認できる氏名・立候補状況等です。

5. 「政策一致度」は公開した計算方法による回答の近さを示す数値であり、能力、人格、実績、適性、当選可能性の評価ではありません。「数値照合対象者」は第18条の条件を満たす候補者です。

## 第3条 参加の任意性と平等な取材機会

1. 運営は把握した全対象者に共通質問票、標準収録時間、回答上限、媒体・許諾範囲、確認手続を同条件で示し、版を記録します。

2. 公開連絡先へ依頼し、少なくとも1回は再連絡します。可能なら別経路も用いますが、特定候補者の露出を優遇しません。

3. 障害、健康上の事情、移動困難等がある場合は書面、オンライン、字幕、休憩等の合理的代替を認め、必要な配慮の詳細を不必要に公表しません。

4. 政策8問、人となり6問、Podcast等の出演、政策一致度への参加はそれぞれ独立した任意参加とし、一部参加・部分回答を認めます。不参加を理由に基本情報や他の許諾済み情報の掲載を排除しません。

5. 不参加の理由や政治的立場を運営が推測せず、状況は第22条の中立的な状態ラベルで表示します。

## 第4条 成人による掲載責任と異議再検討

1. 成人運営責任者堀下 恭平は運営体制、法務相談経路、未成年の業務範囲、緊急時の対応を監督します。ただし、就任だけで個別行為が適法となるものではありません。

2. 成人掲載責任者堀下 恭平（成人運営責任者と兼務）は初回公開、重大な変更、訂正・削除、停止後の再開を最終承認します。編集担当と別の確認担当が原記録と確認版を二者照合し、承認版・媒体・日時を記録します。未承認の公開を認めません。

3. 候補者との選挙活動、雇用、親族、資金、団体その他の具体的利害関係がある担当者は当該判断から外れます。成人掲載責任者本人に利益相反がある場合は、関係のない成人による判断体制が確保できるまで当該候補者に不利益となる最終判断を保留します。差し迫った権利侵害・安全上の危険への暫定停止は第20条に従います。

4. 常設の独立した異議審査担当者は置きません。 一次判断に対する異議は必ず受け付け、初回判断の根拠、申出者の追加資料及び編集担当とは別の確認担当者の意見を記録した上で、成人掲載責任者が再検討します。同じ掲載責任者が再判断するため、独立した第三者審査ではないことを明示します。 重大な権利・公平性の紛争については、必要に応じて外部弁護士等への照会を検討し、客観的検証ができない間は該当表示を暫定停止又は最終判断を保留します。法令上の救済を妨げません。

## 第5条 本人確認、基本同意、数値照合同意

1. 非公開資料の受領又は収録に先立ち、本規約、共通質問票、媒体・利用期間を示す同意書を渡し、本人の署名・適切な電子署名又は本人確認済みメールからの明示的同意を得ます。沈黙は同意ではありません。

2. 本人確認は公式連絡先への折り返し、通話、対面等で実施し、確認方法・担当者・日時を記録します。本人確認書類の写しは原則取得しません。

3. スタッフによる提出は具体的な委任を確認し、一般公開及び追加許諾について必要な本人意思を確認します。

4. 運営・本人双方で規約版、同意書、質問票版、媒体一覧、許諾記録を保管します。

5. 政策回答の掲載同意と政策一致度への数値照合同意は別です。数値照合には対象設問、計算方法、表示・停止・更新条件を記した別紙仕様を渡し、本人の明示的な別途同意を得ます。

## 第6条 回答及び参照資料の扱い

1. 政策回答の選択・理由・条件は本人に確認します。公約、政党の方針、過去発言、第三者評価又はAI推定を本人確認なく本人の数値照合回答に変換しません。

2. 参考資料の提出は全文転載の許諾ではありません。出典・権利を確認し、リンク、適法な引用又は個別許諾を用います。

3. 第三者の非公開個人情報・未許諾素材が含まれる場合は当該部分の不使用や差替えを求めます。候補者に包括的・無制限の補償を求めません。

4. 自由記述を選択尺度に対応付ける場合も、本人の明示的な選択回答確認を得た部分に限って数値計算します。

## 第7条 共通の質問・文字数・表示順

1. 政策8問は共通文面と選択肢を用い、理由・条件は1問400字以内、プロフィールの経歴・紹介は800字以内、人となり6問の書面代替は各600字以内を標準とします。出典URLは字数に含めません。

2. 超過回答の短縮を依頼し、応答がない場合は共通要約枠（400字以内）と原文への同条件の導線を併記します。要約は本人確認対象とします。

3. 候補者の標準表示順は公式立候補届出順とします。届出順確定前は氏名読みの五十音順による仮表示と明記します。政策一致度、閲覧数、人気、回答量による標準順位は設けません。

4. 設問は回答収集前に固定し、変更が必要なら全参加者に同じ改訂・再回答機会を示します。

## 第8条 写真の条件

1. 原則本人単独で顔を確認できる写真1点とします。第三者、児童、権利不明の作品、投票依頼文等について、必要な加工又は差替えを求めます。

2. 撮影者・権利者の許諾、クレジット、加工条件は提出者が確認し申告します。

3. 枠・比率・表示サイズを共通にし、必要なトリミング・明るさ調整のみ実施します。意味を変える加工・生成AI改変は行いません。

4. 仕上がりの写真とサムネイルは確認版に含めます。未提供の場合は共通の中立画像を用います。

## 第9条 Podcast等の収録条件

1. 共通の人となり6問は原則収録7日前までに送付します。準備期間を短縮する場合は本人希望と同意を記録します。

2. 本収録は標準40分以内、公開本編は原則25分以内とし、機材調整・休憩・合理的配慮は別とします。超過は誤解防止等の必要最小限とし理由を記録します。

3. 追記質問は明確化・時系列・根拠の確認等に限り、原則本質問1問につき2回、各1分以内。特定候補者だけの宣伝時間としません。

4. 質問者の説明と候補者本人の発言を明確に区別し、原記録に質問も残します。

## 第10条 中断・オフレコ・再収録

1. 収録開始時に録音・録画の有無、公開媒体、確認手続を再説明し、参加者は休憩・中断を求められます。

2. オフレコは発言前に合意して録音・録画を停止します。合意に反して記録した部分は隔離・削除し、公開・研究利用しません。事後的な指定は第15条・第19条により審査します。

3. 機材事故、運営の質問ミス、健康事情、配慮不足等による再収録は公平に認めます。反響予測や印象改善のみを理由にする撮り直しは原則認めません。

4. 収録中の本人による訂正はその内容を尊重し、原記録との対応を残します。

## 第11条 編集とAI利用

1. 無音・重複・機材音・明白な言い淀みの整理、音量・字幕・文字起こし・共通構成への編集を認めます。

2. 否定、条件、留保、主語、時制、因果関係を変えず、離れた発言の接合で架空の発言を作りません。

3. 要約には原音・原文の出典・タイムコードを付し、運営注と本人発言を区別します。人柄の優劣や政策意図を推測しません。

4. 生成AIは文字起こし又は下案の補助に限り、人間が原記録と照合します。音声合成、架空発言、人物評価、政策の自動補完、無断の学習利用を行いません。

## 第12条 短尺の切り抜きと紹介

1. 短尺抜粋は原則1点90秒以内・1候補者3点以内とし、制作・掲載回数を保証するものではありません。紹介機会の偏りを台帳で点検します。

2. 誇張した賛辞、推薦・優劣を示す見出し、文脈を欠いた煽りを避け、収録日・抜粋である旨・原資料導線を付します。

3. 確認版にない切り抜き・見出し・意味のある再編集は、公開前に第14条に準じた確認機会を設けます。

## 第13条 著作権・肖像・声の利用許諾

1. 著作権その他の権利は移転せず、同意書で特定した範囲で非独占・無償の利用許諾を受けます。本人の氏名・肖像・声は目的・期間・媒体に限ります。

2. 基本媒体https://www.oshisen.com/での掲載と、必要な編集・複製・公衆送信、合意されたアーカイブです。YouTube・Podcast配信サービス・SNS短尺等は同意書で媒体ごとに選択します。

3. 委託先による処理は必要な範囲に限り、商用再販売、政治広告転用、第三者への包括再許諾、生成AI学習は許諾に含みません。

4. 著作者人格権の包括放棄は求めず、著作者・撮影者の権利を尊重します。

5. 外部メディアへのファイル提供、選挙以外への転用、非公開原記録の研究提供は別途の明示的な合意が必要です。

## 第14条 公開前確認と期日

1. 通常の確認版は2026年11月30日12時（日本時間）までに送付し、通常の修正申出期限は12月2日18時です。プロフィール、選択回答・理由、要約、写真・サムネイル、編集済み本編、字幕・文字起こし、予定の切り抜き、媒体一覧を含めます。

2. 本人が閲覧できる確認版、版番号、送達方法、申出先を提示し、他者の未公開回答は開示しません。

3. 閲覧可能となってから最低48時間を保障します。遅延・障害・重大な再編集等の場合は再確認期間を設け、該当部分の公開を遅らせます。

4. 修正申出がなくても新たな同意や権利放棄とはみなしません。送達・閲覧可能性が確認できない部分は公開せず再連絡します。

## 第15条 修正申出の分類

1. 本人は対象箇所、希望する処理、理由・根拠を提示します。権利・安全の懸念は形式が不十分でも受理します。

2. 誤字、原記録との不一致、留保の脱落、資料で確認できる事実誤認、権利・法令上の具体的懸念は「訂正」とします。

3. 選択回答の変更、政策追加、表現の強弱や印象改善は「主張変更」と分けます。期限内の本人明示確定回答による更新は原則1回とし旧版を内部記録に残します。

4. 確認期限後の政策変更は第19条による追記で扱い、事実の訂正を妨げません。

## 第16条 判断・公開承認

1. 編集担当が原記録と出典を照合し、別の確認担当が検証し、成人掲載責任者が承認します。承認を得ない公開はしません。

2. 申出を認めない場合、理由、根拠、規約条項、異議申立て方法を通知します。

3. 運営は構成・見出し等を決定しますが、本人の許諾・原発言・法令上の権利を超えて変更しません。

4. 争いのある要約は原文に戻すか保留し、安全上の懸念は第20条で処理します。

## 第17条 初回公開・遅延参加・更新

1. 初回公開は2026年12月4日の公式届出確認後、選挙区ごとに事前通知した共通時刻に行います。11月20日までに共通時刻を通知します。届出前の予定者を正式候補者と誤表示しません。

2. 全正式候補者の公的基本情報を共通形式で掲載するよう努めます。回答・出演許諾が得られない候補者がいても、他候補者の確認済み情報の公開を自動的に停止せず、未回答等を事実として表示します。

3. 告示日に新たに把握した候補者には24時間以内を目標に共通依頼を行い、回答期間は依頼後72時間を基本に、確認版閲覧後48時間以上を確保します。

4. 遅れて完成した掲載は原則毎日18時の更新枠で反映します。選挙期間中の任意更新は12月12日18時までとし、その確認版は原則12月10日18時までに送付します。間に合わない場合は選挙後のアーカイブに回します。

5. 辞退・届出不成立が確認された者は選挙の比較対象から外し、履歴を混同しない方法で扱います。

6. 追加参加にも同じ同意・本人確認・編集基準を適用し、数値照合には第18条を適用します。

## 第18条 政策比較・一致度・公開判断

1. 標準は設問別の政策回答比較とし、人格点、人気順位、運営による投票推薦、当落予想は作りません。

2. 基本情報・政策回答・人となり回答・Podcastと、一致度数値の公開は別々に判断します。数値照合が非公開でも適法・許諾済み情報を比較できます。

3. 数値照合対象は、本人が共通回答を確認し、数値利用に別途明示的に同意した候補者に限ります。全員同意は必須ではありません。

4. 数値照合は次の自主的な5条件をすべて満たす場合に限り公開します。①正式全候補者中の照合対象者が3分の2以上かつ2人以上、②対象者全員について政策8問中共通6問以上の比較可能回答がある、③利用者も共通設問の4問以上に回答した場合のみ当該利用者へ数値を表示、④計算方法・重み・欠損・意味・限界を公開、⑤成人掲載責任者の承認及び必要な法務確認を完了。これらは法律で定められた割合・問数ではありません。

5. 未回答・不同意・条件未達の候補者には**「算出対象外」**と表示し、0％、反対、中立その他の仮値を割り振りません。全候補者一覧では人数・対象数を明示し、不同意の個別事情は原則公表しません。

6. 計算対象候補者に共通する設問、同じ分母・重み・処理を適用し、「判断保留」「未回答」「中立」を混同しません。各結果に設問数・仕様版を表示します。

7. 数値順に標準掲載順を変更せず、原回答・条件・理由への導線を置きます。人となり情報は点数化しません。

8. 追加・撤回・候補者数の変化等で第4項条件を満たさなくなった場合は当該選挙区の数値照合を一時停止し、再開には再検証・成人掲載責任者承認を要します。適切な個別情報は継続可能です。

9. 公開前に再現性・候補者名置換テスト・欠損値処理テストを行い、仕様変更は変更理由、日時、影響、版を記録・必要に応じ公表します。

10. 法的疑義、公平性上の重大問題、18歳未満の者による禁止行為の懸念がある場合、成人掲載責任者は全体又は一部の公開を保留・停止します。成人責任者の存在は未成年の個別行為を適法化しません。

11. 投票日（12月13日）は新規紹介、任意更新、照合対象追加、新規数値結果の生成・公開を停止します。既存表示についても事前法務確認し、安全上必要な是正は第20条により行います。

## 第19条 公開後の訂正・政策変更

1. 誤記、原記録不一致、根拠のある事実誤認、権利・法令上の問題は公開後も受理します。

2. 訂正理由、日時、対象、計算への影響を記録し、意味のある訂正は利用者にも履歴を示します。任意の全面差替えは行いません。
