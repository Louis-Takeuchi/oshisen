# オシセン｜候補者向け取材コンテンツ取扱掲載規約　デザイン要件

## 1. 目的と適用範囲

対象は、既存の「候補者向け取材コンテンツ取扱掲載規約」（正式案 v1.0、2026年10月10日）の紙面・PDFレイアウトのみとする。候補者へ送付し、印刷しても読みやすい、一般的な規約・契約書に近い、落ち着いた文書体裁に整える。

**本文、前文、全28条・110項、附則、条番号、日付、時刻、期間、URL、メールアドレス、用語、句読点は変更しない。** 要約、校正、言い換え、追記、削除、項目の統合、並べ替え、条番号の変更、見出しの改題は行わない。

ここに示すのは**制作上の推奨仕様**であり、法律上の一律の書式義務を示すものではない。

## 2. 用紙・版面

| 項目 | 指定要件 |
| --- | --- |
| 用紙 | A4縦（210 × 297 mm） |
| 段組み | 1段、縦書きではなく横書き |
| 余白 | 上25 mm／下22 mm／左25 mm／右25 mm |
| 本文幅 | 160 mm（左右各25 mmの余白を差し引いた幅） |
| 配色 | 白地・黒文字。補助文字を使う場合のみ濃いグレー（70%以上の黒） |
| 装飾 | 本文を囲む枠、背景色付きボックス、イラスト、グラデーションは使用しない |
| ページ数 | 固定しない。読みやすい行間・余白と条項の順序を優先する |

## 3. 書体・文字サイズ

| 要素 | 推奨書式 |
| --- | --- |
| 文書タイトル | Noto Sans JP Bold、17 pt、中央揃え |
| 版・日付の行 | Noto Sans JP Regular、9 pt、右揃え。原文の情報と順序を維持 |
| 前文 | Noto Serif JP Regular、10.5 pt、左揃え |
| 「第n条 …」見出し | Noto Sans JP Bold、11.5 pt、左揃え |
| 条内の項（1、2、3…） | Noto Serif JP Regular、10.5 pt、左揃え |
| 附則 | 原文の「附則」表示を尊重し、同じ11.5 ptの見出しスタイルを適用可。ただし文言は保持 |
| フッター | Noto Sans JP Regular、8.5 pt、右揃え |

- 日本語フォントが使えない場合の代替：本文は「游明朝」「ヒラギノ明朝 ProN」「IPAex明朝」等、見出しは「游ゴシック」「ヒラギノ角ゴシック」等を使用する。代替時も字幅・改ページ・禁則を再確認する。
- 文字色は原則 #111111。見出し・本文の文字を政策上の重要性に応じて色分けしない。
- 本文の太字や下線による選択的強調は増やさない。日付・締切・権利・義務を一部だけ大きく目立たせない。

## 4. 行間・段落間隔

| 要素 | 指定要件 |
| --- | --- |
| 本文行間 | 文字サイズの1.5倍を基準（10.5 ptに対し約15.8 pt） |
| 項と項の間隔 | 後6 pt（約2.1 mm） |
| 条見出しの前 | 14 pt（約4.9 mm） |
| 条見出しの後 | 6 pt（約2.1 mm） |
| タイトルの後 | 8〜10 pt |
| 版・日付の行の後 | 12〜14 pt |
| 前文と第1条の間 | 14 pt |
| 段落 | 通常の折り返しは自動。元PDFの紙面上の改行位置は再現しない |

- 日本語の禁則処理を有効にし、「、」「。」や閉じ括弧が行頭に来ないようにする。
- 文字間隔を不自然に詰めたり伸ばしたりせず、1行あたり概ね40〜43文字前後を目安にする。
- 行末・行頭の調整によって文言・句読点そのものは変更しない。

## 5. 条番号と項番号

- 条見出しは、原文の「第1条 目的及び対象」のように、**条番号と見出しを同一行**に置く。
- 第1条から第28条までの見出し階層は統一し、勝手に「章」「節」や中見出しを新設しない。
- 各項の「1」「2」「3」等は原文の番号表記を維持し、左端にそろえる。
- **ぶら下げインデント**を使い、折り返し行は番号ではなく本文の先頭位置にそろえる。目安は番号欄約1.5字分、本文開始位置をそこから約5〜6 mmとする。
- 原文中の「①」「②」などは、独立した箇条書きに組み直さず、原文の文中表記を維持する。
- 番号の直前・直後で不自然に改ページせず、項番号とその本文の1行目を必ず同ページに置く。

## 6. 改ページ・フッター

- 条見出しだけがページ最下段に残らないよう、**見出しと直後の項の少なくとも2行**を同ページに収める。
- 可能な範囲で、項の冒頭・末尾の1行だけが別ページに取り残されることを防ぐ（ウィドウ・オーファン制御）。
- 長い項はページをまたいでよい。無理に1項全体を1ページへ詰め込み、文字サイズや行間を縮めない。
- ページ番号は自動生成とする。原PDFのフッター文字列「オシセン 2026県議選版 | A | ページ番号」を再現する場合は、最終的なページ数に合わせて番号だけ自動更新する。
- フッターは右下、紙面下端から約10〜12 mmを基準とし、本文領域と接触させない。
- 頭書や余分な「取扱注意」スタンプ、押印欄、署名欄、注意書き、目次を追加しない。

## 7. 形式上の中立性

- 行政機関の正式文書と誤認されるような県章、公印風デザイン、選挙管理委員会のロゴは使用しない。
- 候補者、政党、選挙区、政策分野によって装飾や強調の仕方を変えない。
- オシセンのブランドカラーを本文中で多用しない。ロゴを新たに配置しない。
- 規約の読みやすさを優先し、Webサイトの広告・ポスターに近いポップなデザインにはしない。

## 8. PDF出力・品質確認

1. Markdown原稿を正本として使用し、PDF組版の都合による文章の短縮・分割・書き換えを行わない。
2. 日本語フォントを埋め込み（可能ならサブセット化）、PDFから文字を選択・検索・コピーできるようにする。
3. URLとメールアドレスは原文どおり表示する。リンク機能を付けても表示文字列は変更しない。
4. A4・100%倍率・白黒印刷で、行間、余白、見出し、項番号を確認する。
5. 全ページについて欠字・文字化け・重なり・はみ出し・項番号の消失・途中の意図しない改行を検査する。
6. 第1〜28条・計110項・附則が揃っていることを確認する。
7. 原文と出力文書の全文を照合し、改行・組版用空白・自動フッター以外の文字列差分がゼロであることを確認する。

## 9. 完成イメージ

**白いA4紙／余裕のある余白／中央の文書タイトル／右側の版・日付／明朝の本文／黒太字の条見出し／番号位置がそろった項／右下の控えめなページ番号。**

装飾によって「権威」を演出するのではなく、統一された文字組みと正確な条番号、読みやすい余白で正式文書らしさを出す。
